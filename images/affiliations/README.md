# Institution logo assets

Original logo files are kept in this directory. The homepage uses the normalized
PNG files in `normalized/` so every logo is placed on an identical 512 × 512
canvas after external whitespace has been trimmed.

Place original transparent SVG, PNG, or JPG files here using these names:

- `ustc.svg` or `ustc.png`
- `livsyn-robotics.svg` or `livsyn-robotics.png`
- `hkust-gz.svg` or `hkust-gz.png`
- `ucas.svg` or `ucas.png`
- `ncepu.svg` or `ncepu.png`

Prefer official assets. When adding or replacing a logo, regenerate its normalized
counterpart before updating the matching `<img>` element in `_pages/about.md`.
